# Time2Graze workshop — refined visual version

An isolated design and implementation variant of the workshop site. It preserves the confirmed content and operational behaviour of the main project while exploring a more content-specific visual system.

The interface uses a curated Phosphor icon subset: regular icons for navigation and reading, duotone icons for larger operational categories, and bold/fill only for confirmed or selected states. The workshop name remains typographic; the icon set is not used as an invented event mark.

Run locally with:

```bash
npm install
npm run dev
```

## Production requirements

1. Open each selected image and compare it with its caption. Check actual subject, date, recognisable people, sharpness and whether the intended crop removes useful context. Write final alt text after this inspection.
2. Download only files selected for legitimate licensed production. Keep original source URL, author, licence, verification date and unmodified original reference in the asset record. Save produced variants under `public/` only when ready to use.
3. Make responsive WebP/AVIF variants with a broadly supported fallback where needed. Do not upscale small files to impersonate additional detail. Record crops and tonal edits.
4. Preserve original photographs of real places. No generated building, crowd, wildlife or pasture scene should be passed off as documentary material from Goiás. Vector diagrams can explain concepts without pretending to be evidence.
5. Include a readable credit beside each displayed image or in the gallery's persistent caption area. An example for M01: “Photo: Fronteira / Wikimedia Commons · CC BY-SA 4.0.” Add “cropped” only if a crop was actually made and keep source/licence links accessible.
6. For a gallery, define ordered image IDs, rather than copying photo objects into multiple story files. Never count the same view twice as distinct content.
7. Use loading placeholders with fixed aspect ratios. Do not fetch full galleries while the story is closed; load the selected image and at most its immediate neighbour.
8. Confirm every English caption distinguishes historical photographs, regional examples and actual workshop locations. File years are not the date of this workshop.
